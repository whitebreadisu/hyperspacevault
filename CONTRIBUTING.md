# Contributing

Thanks for taking an interest in HyperspaceVault. This is a small project with one owner, so here is how things work.

## Reporting

The fastest route is the **Leave Feedback** button in the app header at [www.hyperspacevault.com](https://www.hyperspacevault.com) (on a phone: More, then Leave Feedback). It works signed in or out, and it is the right place for anything about your own account or collection.

For everything else, open an [Issue](../../issues/new/choose) using one of the two templates: a bug report or an idea.

A report is easy to act on when it says:

- what you did, step by step, and what you expected to happen instead
- what actually happened (a screenshot helps; please crop out anything private)
- your device and browser

## How this project is built

HyperspaceVault is owner-directed, AI-assisted engineering: the owner decides what gets built and why, and Claude Code builds and reviews it under written briefs. Work is tracked in a private registry and surfaced publicly on [ROADMAP.md](ROADMAP.md).

## Pull requests

Pull requests are not solicited. The codebase is public for reading and learning, and you are welcome to fork it. A pull request will be read, but the roadmap is set by the owner, so please do not be disappointed if it is not merged.
